# Waddler toSQL
<Prerequisites>
- Quick start with Waddler - [read here](/docs/mssql/get-started/mssql-new)
- Waddler SQL template - [read here](/docs/mssql/sql-template)
</Prerequisites>
<br/>

`.toSQL()` prepares and prints you SQL query as `{ query: string, params: any[] }`:
```ts
console.log(sql`select * from users;`.toSQL());
console.log(sql`select * from users where id = ${10};`.toSQL());
```

```shell
{
  sql: "select * from users;",
  params: [],
}
{
  sql: "select * from users where id = @p1;",
  params: [10],
}
```
