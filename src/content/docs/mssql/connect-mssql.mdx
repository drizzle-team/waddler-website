# Waddler \<\> MySQL

To use Waddler with a MsSQL database, you should use the `mssql` driver

Waddler natively supports `mssql` with `waddler/node-mssql` package.

#### Step 1 - Install packages
<Npm>
waddler mssql
</Npm>
