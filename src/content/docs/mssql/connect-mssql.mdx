# Waddler \<\> MySQL

To use Waddler with a MsSQL database, you should use the `mssql` driver

Waddler natively supports `mssql` with `waddler/node-mssql` package.

#### Step 1 - Install packages
<Npm>
waddler mssql dotenv
</Npm>

#### Step 2 - Initialize the driver and make a query
<CodeTabs items={['node-mssql', 'node-mssql with config', 'your mssql driver', 'AutoPool']}>
<Section>
```typescript copy
import 'dotenv/config';
import { waddler } from "waddler/node-mssql";

const sql = waddler(process.env.DATABASE_URL);

const result = await sql`select 1;`;
```
```ts copy
// process.env.DATABASE_URL should be provided in the following format:
`Server=<server>,<port>;Database=<database>;User Id=<user>;Password=<password>;Encrypt=<encrypt>;TrustServerCertificate=<trustServerCertificate>;`
```
</Section>

<Section>
```typescript copy
import 'dotenv/config';
import { waddler } from "waddler/node-mssql";

// connection can accept either a database url or an mssql config
const sql = waddler({ connection: process.env.DATABASE_URL });

const result = await sql`select 1;`;
```
```ts copy
// database url should be in the following format:
`Server=<server>,<port>;Database=<database>;User Id=<user>;Password=<password>;Encrypt=<encrypt>;TrustServerCertificate=<trustServerCertificate>;`

// mssql config example:
{
	server: 'localhost',
	port: 1433,
	database: 'master',
	user: 'SA',
	password: '...',
	pool: {
		max: 1,
	},
	options: {
		requestTimeout: 100_000,
		encrypt: true, // for azure
		trustServerCertificate: true,
	},
}
```
</Section>

```ts
import 'dotenv/config';
import { waddler } from "waddler/node-mssql";
import mssql from 'mssql';

async function main() {
  // mssql.connect can accept either a database url or an mssql config
  const client = await mssql.connect(process.env.DATABASE_URL);
	await client.connect();

	const sql = waddler({ client });

	const result = await sql`select 1;`;
}

main();
```
