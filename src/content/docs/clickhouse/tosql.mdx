# Waddler toSQL
<Prerequisites>
- Quick start with Waddler - [read here](/docs/clickhouse/get-started/clickhouse-new)
- Waddler SQL template - [read here](/docs/clickhouse/sql-template)
</Prerequisites>
<br/>

`.toSQL()` prepares and prints you SQL query as `{ query: string, params: any[] }`:
```ts
console.log(sql`select * from users`.toSQL());
console.log(sql`select * from users where id = ${10}`.toSQL());
```

```shell
{
  sql: "select * from users",
  params: {},
}
{
  sql: "select * from users where id = {param1:String}",
  params: { "param1": 10 },
}
```
